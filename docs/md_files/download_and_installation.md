# Downloading the Code

[PARTIES_Install](https://github.com/metialex/PARTIES/tree/master/PARTIES_Install) is included in the repository and contains the required libaries for installing or compiling, respectively, the PARTIES code. Therefore, you should firstlye clone the repository to your local machine.

<pre>
git clone <em>URL</em>
</pre>

The mentioned libraries are in <em>.tar</em> and <em>.tar.gz</em> format and need to be unpacked. Unpack the files to a local directory, which we will call <b>your_directory</b> in the following commands.

<pre>
tar -xf <em>tar-file</em> -C <b>your_directory</b>
</pre>
