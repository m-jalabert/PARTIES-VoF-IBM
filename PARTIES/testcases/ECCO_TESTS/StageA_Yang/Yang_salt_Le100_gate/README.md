# Yang finite-interface salinity gate (Le = 100)

## Controlling result

**STOP -- do not run the refined gate, a `Sc=500` branch, or another Yang
production case.**  The optional salt-only mapping tested here is stable, but
it does not improve the analytic liquid-salinity profile or Stefan-front
constant.  Keep `phase_change.yang_salt_transport = 0` in production inputs.

This gate discriminates the legacy PARTIES masked-diffusion salt equation from
a mapping of the finite-interface salinity equation used by Yang et al. (2023)
and AFiD-MuRPhFi.  It is deliberately one-dimensional, quiescent, and short so
that a model-form hypothesis can be rejected before any production-scale
branch is launched.

## Cases

All cases use `Pe_T = 100`, `Pe_S = 10000` (`Le = 100`), `St = 0.5`, a
`768 x 4 x 1` thin strip, zero velocity, and stop at `t = 0.5`.  Each pair is
identical except for `phase_change.yang_salt_transport`:

- `parties_legacy.inp`: existing PARTIES masked diffusivity (`0`);
- `parties_yang.inp`: experimental Yang salt mapping (`1`, `delta = 1e-6`);
- `parties_similarity_legacy.inp` and `parties_similarity_yang.inp`: the same
  comparison restarted at `t = 0.25` from common analytic temperature,
  salinity, and front profiles generated by `make_similarity_seed.py`.

The experimental branch combines the molecular and phase-gradient diffusion
terms in the continuum-equivalent flux form

```text
(1/Pe_S)/(F+delta) div[(F+delta) grad(S)]
```

and adds `-S*melt_src/(F+delta)`.  The combined diffusion is implicit and its
CG solve uses the `(F+delta)`-weighted inner product.  This is a stable mapping
of the salt equation onto PARTIES; it is **not** the complete Yang method,
because PARTIES still evolves a conservative Cahn--Hilliard phase field rather
than Yang's Allen--Cahn/Hester phase equation.

## Results

The production-like start (`S` smoothed with the liquid fraction) completed in
Slurm job `19427758`:

| branch | lambda relative error | final liquid-S Linf | physical-salt drift |
|---|---:|---:|---:|
| legacy | 0.6039 % | 1.441e-2 | 2.764e-3 |
| Yang mapping | 0.8945 % | 8.773e-2 | 2.599e-4 |

The mapping conserves `(F+delta)S` about 10.6 times better, but makes the final
profile error 6.09 times larger and the front error 1.48 times larger.

The smooth nonzero-time similarity restart completed in Slurm job `19427886`:

| branch | lambda relative error | final liquid-S Linf | physical-salt drift |
|---|---:|---:|---:|
| legacy | 0.5742 % | 4.371e-4 | 9.458e-6 |
| Yang mapping | 0.6243 % | 8.719e-4 | 1.356e-5 |

Both branches remained finite and quiescent, salinity stayed bounded, and
enthalpy drift was below `2e-10`.  Starting from a smooth analytic state removes
the production-like startup discontinuity as an explanation: the salt-only
mapping still doubles the profile error and worsens the front constant.

Two earlier direct explicit-split implementations were stopped as soon as an
interface mode appeared near `t = 0.0045`; their outputs are retained in
`run_yang_failed_full_phase_increment/` and
`run_yang_failed_explicit_split/`.  They are failure provenance, not results to
continue.

## Reproduce the audit

`jobscript_yang_retry.sh` runs the completed production-like comparison.
`jobscript_similarity.sh` creates the common analytic seed and runs the two
smooth-start branches sequentially.  `analyze_gate.py` writes the comparison
CSV and Markdown decision.  Existing controlling outputs are:

- `gate_comparison.csv` and `gate_summary.md`;
- `similarity_gate_comparison.csv` and `similarity_gate_summary.md`.

The predeclared rule required the experimental branch to be finite, conserve
physical salt to 1 %, and improve either the liquid salinity profile or the
front constant.  It improved neither metric in either initialization, so a
refined run is rejected.
